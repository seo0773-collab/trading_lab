> **yoon_profile + 떨어지는 칼 셀 숏 + 스퀴즈 가드.** 2D 상태 그리드(멀티플×기울기)의
> (0,0) "떨어지는 칼" 셀에서 −0.5 숏을 잡되, 숏 에피소드 최저 종가 대비 **+15% 반등
> 시 에피소드 종료까지 숏 금지**(trail15 가드)로 스퀴즈를 방어한다.

## 2. yoon_profile과의 차이

1. `state_weights[0][0] = −0.5` (떨어지는 칼 셀 숏. 스터디: 전 horizon 음수·WF 일관 음수)
2. `short.enabled = true` → 음수 비중 허용 (기본 off인 yoon_profile은 동작 불변)
3. `short.trail_pct = 0.15` 스퀴즈 가드: 숏 에피소드(연속 음수 목표 구간) 중 최저
   종가 대비 +15% 반등하면 그 에피소드가 끝날 때까지 숏 목표를 0으로. 인과적
   (당일 종가까지만 사용, 비중은 다음 봉 적용).
4. 거래 분해가 양방향(`signed_lot_trades`): 부호 전환 시 전량 청산 후 반대 방향
   진입, 가드 발동 봉의 숏 청산은 `exit_reason=squeeze_guard`.

## 3. 검증 요약 (2026-07-03)

숏 후보 선별 → 가드 선정 2단계, 각 단계 사전 예측 후 백테스트 대조:

- (2,1) 감속 숏 **기각**: 전기간 착시(holdout Sharpe 0.395→0.221 붕괴).
- (0,0) 칼 숏 무방비는 보류(엣지=2022 단일 에피소드, 숏 스퀴즈에 MDD 취약).
- 가드 비교: **trail15만 전 구간 개선.** ma20 가드(베어랠리마다 껐다켜서 이득 소진),
  trail10(과민), fast_exit(되돌림에서 불리) 모두 기각.

## 4. 주의 / 무효화 조건

- **펀딩비용 미반영**: 현물 숏 불가 → 실거래는 선물. 펀딩은 역사적으로 롱→숏
  지급이 우세라 유리한 편향이지만, 실계좌 검증 전 확정 금지. `live_eligible=False`.
- trail 15%는 {10, 15} 중 선택된 값(경미한 선택 편향). 하락장 표본 2개.
- 베이스 yoon_profile의 유보(셀 가중치의 전 기간 통계 의존)도 그대로 상속.

  베이스 yoon_profile 무효화 조건 발동 시 함께 폐기.
