# final0706 개선 계획 (2026-07-07)

비판적 평가(세션 실측)에서 확인된 결함을 우선순위별로 복구하는 계획.
**config 동결 정책 준수**: 전략 파라미터는 일절 건드리지 않는다. 대상은
리포트 파이프라인의 계측 버그, 공표 수치의 정직화, 검증 공백 보강, 운영 게이트다.

## Phase A — 수치 진실성 복구 (P0, 다른 모든 것의 전제)

### A1. 연환산 버그 수정
- `scripts/profile_sizing/engine.py:130`의 `n_years = len(equity)/ann`을
  DatetimeIndex면 달력 기준(`(end-start).days/365.25`)으로 변경.
- final0706 스크립트 7종(`final0706_full_param_sweep{,_v3}`, `4h_backtest`,
  `4h_optimize`, `4h_full_cross_sweep`, `period_scale_cross_tf{,_v2}`)에 복붙된
  동일 metrics를 공통 유틸로 추출(예: `scripts/profile_sizing/metrics.py`).
  단, 4h 등 인트라데이는 실제 연간 봉 수 방식이 맞으므로 "달력 우선, 인트라데이는
  기존 방식 유지" 분기.
- **완료 기준**: 결측 연도가 낀 인덱스에서 달력 CAGR을 반환하는 단위 테스트 +
  전체 테스트 통과.

### A2. 데이터 갭 정직화
- 2007년 stray 8봉의 정확한 원인 규명(KR ETF 상장 직후 초기 봉으로 추정,
  yoon1j_kr NAV 시작점·yfinance `.KS` 초기 데이터 확인).
- 평가 표준 시작점을 데이터 연속 구간(2009-04 또는 보수적으로 2011-01)으로 정의,
  리포트에 갭 라벨(`2007-01-29~ (2007-02~2009-04 결측)`) 자동 표기.
- **완료 기준**: 원인 진단 노트 + 시작점 규칙이 비교 스크립트에 반영.

### A3. 핵심 리포트 재실행 (benchmark_compare v2)
- 달력 CAGR + 표준 시작점으로 재실행. phase를 `all(2011~)`, `2011~2024`,
  `2025~`(랠리 구간 분리), `test`로 재편. 부트스트랩 재실행.
- 스윕 v3는 순위 비교라 결론 불변 가능성이 높음 — 전면 재실행 대신
  베이스라인·상하위 3개 조합 스팟 체크로 검증, 달라지면 그때 재실행.
- **완료 기준**: `final0706_benchmark_compare_v2.md` 생성, 구 리포트에 정정 헤더 추가.

### A4. 공표 수치 정정
- `docs/strategy/specs/final0706*.md`, `checklists/final0706*.md`,
  `registry.py` description의 16.84%/1.242를 달력 기준 수치+구간 라벨로 정정.
  final0706_qld(24.72%)·final0706_4h 문서도 연쇄 정정.
- `configs/strategies/final0706.json` `_comment`의 수치 정정은 **동결 예외**
  (파라미터 불변·주석만) — 실행 전 사용자 승인 필요.
- **완료 기준**: "16.84%"가 정정 문맥 없이 남아 있는 문서 0건.

## Phase B — 리스크 검증 공백 보강 (P1, A1 이후)

### B1. 신용게이트 GFC 대리검증 — 위기 표본 n=1→2 (최고 가치)
- `yoon2m_gfc_proxy.py`의 SPDR 유니버스(1998~) 구조에 final0706의 HYG/IEF
  게이트를 적용. **HYG 2007-04 상장이라 GFC(2007-10~2009-03)를 커버**함.
- 측정: GFC에서 발동 시점·리드타임(코로나 -48일과 비교)·MDD 기여.
  2011·2015·2018·2022 에피소드도 동일 유니버스에서 재측정.
- **판정 기준 사전 등록**: GFC에서 발동 실패 또는 리드타임 사후(+)면
  "게이트=코로나 특화" 결론을 스펙에 명시하고 게이트 없는 파생과 병행 페이퍼로 강등.
- 산출물: `final0706_credit_gate_gfc_proxy.md`.

### B2. 양도세 반영 시뮬
- 해외 상장분 양도세 22%(연 250만 기본공제, 매도 시 실현손익 통산, 연말 과세),
  국내 주식형 ETF 매매차익 비과세로 세후 NAV 재계산.
- 비교: 세후 final0706 vs 세후 SPY/QQQ_KRW B&H(과세 이연, 최종 청산 시 일괄).
  적립식(월 20만) 시나리오 포함 — 실사용 계좌 조건과 일치.
- **완료 기준**: 세후 CAGR 격차 정량화. 격차가 위험조정 우위를 상쇄하면
  회전 억제 파생(hold_buffer↑ 또는 연간 리밸런스) 검토를 후속 과제로 등록.
- 산출물: `final0706_tax_impact.md`.

### B3. 레짐 의존 분해
- 2025-26 수익 기여 분해(VGT vs 나머지 US top3 vs KR 슬리브 vs 통화틸트 vs 게이트).
- 2011~2016 저성과(연 0.2~5.6%) 원인 진단(섹터 로테이션 무효 레짐인지, KR 슬리브
  드래그인지).
- **완료 기준**: 스펙에 기대치 절 추가 — "테크 랠리 부재 레짐에서 한 자릿수
  CAGR/Sharpe 0.9대가 기본 기대치"를 명문화.
- 산출물: `final0706_regime_attribution.md`.

## Phase C — 전진검증 운영 (P2, A·B와 병행 가능 — 빨리 시작할수록 좋음)

### C1. 페이퍼 저널 개시 (즉시)
- `var/paper_trading/` 기존 yoon1j 저널 인프라를 재사용해 final0706 저널 추가.
- **게이트 유/무 두 트랙 병행 기록** — B1의 반증 조건을 라이브로도 검증.

### C2. 판정 기준 사전 등록
- 3개월 추적오차 밴드(백테스트 대비 월간 수익률 괴리 허용치), 게이트
  발동/오발동 기록 양식, 실체결 슬리피지 vs 가정 5bp 검증 방법을 미리 문서화.
- holdout 오염(F6)의 유일한 해독제가 이 전진검증이므로, 기준을 결과를 보고
  바꾸지 않도록 사전 커밋.

### C3. 승격 판단 (2026-10 이후)
- 페이퍼 3개월 + KIS 실수수료 실측 + B1/B2 결과를 종합해 live_eligible 결정.
- QLD 파생은 코어 승격 이후에만 검토.

## Non-goals (하지 않는다)

- 파라미터 재튜닝 — 72조합 스윕에서 개선 없음 확인, 동결 유지.
- 새 알파 레이어 추가 — 동결 정책. 실험은 별도 파생으로만.
- 4h 압축 재도전 — 미완성으로 판정된 별도 트랙, 이 계획과 무관.

## 순서와 의존성

```
A1(연환산 수정) → A2(갭 정직화) → A3(리포트 재실행) → A4(문서 정정, 사용자 승인 1건)
A1 이후 병렬:      B1(게이트 GFC)   B2(양도세)   B3(레짐 분해)
즉시 병행:         C1(페이퍼 개시) → C2(판정 기준) → C3(승격, 2026-10+)
```

규모 감: A는 반나절(코드 소량+재실행), B1·B2 각 반나절~1일, B3 반나절, C1 소량.
