# 전략 명세: yoon2m

> `yoon2`의 구조는 그대로 두고 두 슬리브의 `top_k`만 3으로 줄여 보유 종목을 6종(US3 +
> KR3)으로 집중한 **저예산(mini) 파생**. 목적은 **200만원 정수주 자동매수 적합성**과
> yoon2의 낙폭방어 보존이다. SSO 레버리지는 쓰지 않는다(방어 우선).

## 1. 식별 정보

| 항목 | 값 |
| --- | --- |
| strategy_id | yoon2m |
| 기반 전략 | yoon2 (yoon1j_lp USD + yoon1j_kr KRW, 50/50) |
| 변경점 | 두 슬리브 `top_k`: 11/5 → **3/3** (inline override) + US universe IXN→**VGT** (2026-07-05) |
| 보유 종목수 | 6종 (US 3 + KR 3) |
| 레버리지 | 없음 (SSO 미사용) |
| 리밸런싱 | 월간 |
| 기준 통화 | KRW, USD 슬리브는 USD/KRW 환산 |
| 핸들러 | `src/trading_lab/strategies/yoon1k.py` (`Yoon1kHandler`) |
| config | `configs/strategies/yoon2m.json` |

## 2. 동기 — 왜 저예산 파생이 필요한가

yoon2a(17종, 위성 1~3%)를 200만원 정수주로 집행하면 10/17 종목이 0주가 되고 현금이
45% 놀아 전략이 깨진다(SSO+한국 두 덩어리로 쏠림). 원인은 `top_k`가 커서 종목당
비중이 잘게 쪼개지는 것. `top_k`를 줄이면 종목당 비중이 커져 정수주로도 목표에
근접한다. 추세게이트 방어(market_filter + safe_sleeve + regime_cap)는 슬리브 메커니즘
그대로라 보존된다.

## 3. 채택 근거 (top_k 스윕, 2007~2026)

| 전략 | CAGR | MDD | Sharpe | 총수익 | 종목수 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 패시브 50/50 벤치 | 16.78% | -31.35% | 1.090 | 1134% | — |
| yoon2 (기본 11/5) | 14.10% | -14.46% | 1.150 | 747% | 16 |
| yoon2m top_k=1 | 17.39% | -25.27% | 1.006 | 1243% | 2 |
| yoon2m top_k=2 | 15.76% | -20.43% | 1.107 | 969% | 4 |
| **yoon2m top_k=3 (채택)** | **15.30%** | **-18.06%** | **1.157** | **903%** | 6 |

`top_k`를 줄일수록 CAGR/총수익은 오르지만 MDD가 나빠지고 Sharpe가 떨어진다(분산
소실 → 방어 약화). `top_k=1~2`는 MDD가 패시브(-31%) 수준으로 방어가 무너진다.
**`top_k=3`이 방어를 최대 보존(MDD -18.06%, Sharpe 1.157=표 전체 최고)하면서도 6종으로
정수주 적합**한 균형점이라 채택한다. 원본 yoon2를 CAGR·총수익·Sharpe에서 동시 개선하며
MDD만 -14.46%→-18.06%로 소폭 양보(여전히 패시브의 절반대).

## 4. 엣지 검증 (yoon2a와 동일 검정)

산출: `reports/profile_sizing/yoon2m_validate.json`

- **부트스트랩**(5000회, 블록20일): P(Sharpe>0)=100%, **P(MDD<벤치)=95.2%**(방어 통계
  확정), P(Sharpe>벤치)=58.6%(우위는 노이즈), 초과CAGR 중앙 -2.2%(수익은 벤치에 양보).
- **워크포워드**: 연도별 MDD방어 12/18, **롤링3년 MDD방어 17/18(94%)**.
- 정체성: "**낙폭방어가 통계로 입증된 방어형** + 원본 yoon2보다 개선된 수익 + 정수주
  자동매수 가능". 벤치를 위험조정에서 *이긴다*는 주장은 하지 않는다(노이즈).

## 5. 200만원 정수주 적합성

보유 6종 각 ≈16.7%(=각 333,000원). 예산제약 그리디 배분 실측(2026-06): 94% 투자·
현금 6%·추적오차 8.08%p(주범=IXN 고가로 1주만 가능). yoon2a 정수주(54% 투자·0주
10종)와 대비해 전략이 살아있는 수준.

**IXN→VGT 교체(2026-07-05)**: 추적오차 주범인 고가 IXN(≈21.8만원)을 저가 VGT
(≈18.1만원, corr 0.969)로 교체(`yoon2m.json` universe override). 근거=시드×유니버스
스윕(`yoon2m_seed_universe_sweep.md`)에서 전 시드 일관 +0.15~0.27%p, 재검증
(`yoon2m_vgt_validate.json`)에서 CAGR 15.49%/MDD -17.89%/Sharpe 1.169로 전 지표
개선 + **P(MDD<벤치)=95.6%** 방어 게이트 재통과 → 채택.

## 6. 주의 / 무효화 조건

- 보유 종목은 **매월 점수 상위 top_k로 교체**된다. 매입표는 해당 월 리밸런스 한정.
- 평시(강세장)엔 노출 100%·동일가중처럼 보이나, 하락장엔 방어 레이어(노출↓·시장필터·
  TLT/IAU 안전자산 회전)가 켜져 매입표가 통째로 바뀐다.
- 저가 ETF 유니버스 일부가 ~2013 상장이라 초기 구간(2007~2012)은 가용 종목으로만
  백테스트(2008 GFC 부분 반영). 방어 결론은 2011·2018·2020·2022 하락장에서 재현됨.
- **무효화**: holdout/실데이터 검증에서 MDD가 패시브(-31%) 수준으로 벌어지거나
  P(MDD<벤치)가 부트스트랩에서 95% 미만으로 떨어지면 방어 정체성 상실로 폐기.
- `live_eligible=False` 유지 — 모의 전진검증 우선. 실거래는 게이트 통과 후.
