# 전략 명세: new0707

> **SMA10 기울기 가속도(최근 10봉) × 거래량 서지**의 expanding percentile 3×3
> 그리드 상태별 가중치로 long-only 비중을 정하는 단일종목 전략(기본 BTC/USDT 일봉).
> 출발점은 "최근 10봉에 모든 걸 분석"(2026-07-07 설계 대화) — 처음 계획한
> "직전 10봉 프렉탈(유사패턴 투영/자기연장)" 축은 스터디에서 기각되어 폐기했다.

## 2. 지표 (플랜 고정 파라미터 — 스윕 금지)

```
sma10      = SMA(close, 10)
slope_pct  = sma10.pct_change(1)                       # 1봉 기울기(%)
accel_pct  = slope_pct − slope_pct.shift(5)             # 기울기의 변화량(가속도, 부호 보존)
accel_z    = accel_pct / rolling_std(accel_pct, 60)
accel_deg  = degrees(arctan(accel_z))

vol_ratio  = volume / rolling_mean(volume, 60)          # 거래량 서지 배율
vol_z      = (vol_ratio − 1.0) / rolling_std(vol_ratio − 1.0, 60)
```

bin 경계는 yoon_profile과 동일하게 **expanding window percentile**(시점 t까지
포함, 최소 120 유효표본)로 3분위 산출 — look-ahead 차단. `z_window`/
`min_bin_history`는 SMA200 계열(252)보다 짧게 잡았다(10봉짜리 빠른 신호라 최근
변동성 레짐에 더 빨리 맞춰져야 한다는 판단, 잠정값 — 스터디 재검증 대상).

## 3. 프렉탈 축 — 검증 후 기각 (2026-07-07)

원래 설계는 "이전 10봉의 유사 패턴이 다음 10봉 점수에 반영"되는 축을 accel×vol
그리드에 앙상블하는 것이었다. `yoon_pattern`(L=300/H=21 analog, IC +0.056로 채택된
전례)을 L=10/H=10으로 그대로 축소해 재검증했으나:

- **analog**(유사 과거 10봉 앙상블): IC −0.016~−0.039(M=30/50), 1/3구간 부호
  불일치, 5분위 비단조 → 신호 없음.
- **self**(자기 패턴 연장): IC +0.061로 얼핏 양수이나, quintile을 평균 대신
  **중앙값**으로 다시 보면 순위가 완전히 뒤집힌다(평균 40/−17/33/21/326bps vs
  중앙값 34/54/14/−12/234bps) — 5분위 최상단 평균이 최대 54%(5423bps) 단일
  이벤트로 왜곡된 것. 반복 가능한 엣지가 아니라 이상치 구동 착시로 판정.

**결론**: L=300(연 단위 구조)에서 유효했던 analog 투영은 L=10(2주 캔들 모양)에서
재현되지 않는다 — 두 축 다 기각, 프렉탈 컴포넌트 없이 accel×vol 그리드만 채택.

## 4. 상태그리드 검증 결과 (2026-07-07, BTC/USDT 일봉 2017-08~2026-07)

forward 5/10/20일, Newey-West(lag=h) t-stat, 셀 최소 50표본, Bonferroni+BH-FDR
(27검정) 병기. 유효표본 3,006봉(워밍업 이후).

| 결과 | 판정 |
| --- | --- |
| FDR 유의 셀 | **0/27** — 개별 셀 통계적 확정 없음 |
| 셀 부호 | **27/27 전부 양수** — BTC 강세 드리프트가 전 상태를 지배(숏/현금 대상 셀 없음) |
| 방향 일관 셀 | (accel=0,vol=0) 감속+한산이 5/10/20일 전부 최고 순위(t=+3.08/+2.68/+2.05, |t|>1.65는 h=5,10) |
| 최저 셀 | (accel=0,vol=2) 감속+거래량 급증(소진/캐피튤레이션 추정)이 3horizon 전부 최저 근처(h=5 t=+0.09, h=10 t=+0.05) |

해석: 대각선 두 셀 — (0,0) 감속+한산(눌림목류)과 (2,2) 가속+거래량확인
(모멘텀+볼륨 동의) — 이 상위, "가속상태와 거래량이 불일치"하는 셀(감속인데
거래량 급증=소진, 가속인데 거래량 없음=약한 확인)이 하위. 방향은 3horizon 모두
일관되지만 FDR 미달이므로 **가설 검증이 아니라 방향성 tilt**로만 취급한다.

## 5. 사이징 체인

```
state(t) = (accel_bin, volsurge_bin) ∈ 3×3   (expanding percentile, 인과)
  → target_weight = state_weights[accel_bin][volsurge_bin]   (config 행렬)
  → 점진 리밸런스 (threshold 0.05, 봉당 최대 0.25)
  → engine.portfolio_returns: 비중 1봉 지연 적용 + 회전율 비례 비용
```

기본 `state_weights` (3horizon 평균 fwd return 순위 1~9를 0.4~1.0에 선형 매핑,
스윕 아님 — FDR 미확정이므로 극단값(0.0/1.0 온오프) 대신 완만한 tilt로 보수화):

| accel\vol | 0 (한산) | 1 (보통) | 2 (서지) |
| --- | --- | --- | --- |
| 0 (최대감속) | 1.000 (최고) | 0.700 | 0.400 (최저) |
| 1 (중립) | 0.550 | 0.775 | 0.475 |
| 2 (최대가속) | 0.625 | 0.850 | 0.925 (2위) |

## 6. 백테스트 결과 (BTC/USDT 일봉, 수수료+슬리피지 왕복 10bp)

| phase | 전략 수익 | Sharpe | MDD | B&H 수익 | B&H Sharpe | B&H MDD |
| --- | --- | --- | --- | --- | --- | --- |
| all (2017-08~) | +634.9% | 0.624 | −66.6% | +1347.1% | 0.654 | −83.2% |
| validation | +135.8% | 1.319 | −18.6% | +257.1% | 1.431 | −26.2% |
| test (holdout) | −1.4% | 0.100 | −36.8% | −2.1% | 0.160 | −53.0% |

**정직한 결론**: 이 tilt는 **Sharpe에서 B&H를 한 번도 이기지 못한다**(all/validation/
test 3구간 모두 B&H Sharpe가 근소하게 더 높음). MDD는 3구간 전부 개선하지만,
그 대가로 수익도 함께 줄어들어 위험조정 성과(Sharpe)는 순수 노출 축소와 별
차이가 없다 — 즉 "국면을 읽어서 얻는 알파"가 아니라 "평균 노출을 낮춰서 얻는
낙폭 완화"에 가깝다. state_weights 범위(0.4~1.0)가 애초에 완전 현금화 구간이
없어 하락장 방어력도 제한적이다. FDR 0/27이라는 스터디 결론과 정합적인
결과 — **이 전략은 확정된 알파가 아니라 노출 축소형 방어 tilt로만 취급한다.**

## 7. 주의 / 무효화 조건

- **FDR 유의 셀 0/27** — 이 전략은 "확정된 알파"가 아니라 "방향 일관 tilt"다.
  `live_eligible=False`, 페이퍼/추가 데이터 검증 전 승격 금지.
- 셀 부호가 전부 양수인 것은 BTC 표본 기간(2017~2026)의 강세 드리프트 지배
  때문일 가능성이 크다 — 하락장/횡보장 표본에서 이 상대 순위가 유지되는지 별도
  확인 필요(현재 미검증).
- 프렉탈 축 기각은 L=10/H=10 조합에 한한 결론이다. 다른 L(15~30봉)에서 재탐색할
  여지는 있으나, 사용자 원 가설("최근 10봉")과는 범위가 달라지므로 재탐색 시
  전략명·명세를 분리한다.
- **무효화**: 신규 데이터 누적 후 스터디 재실행에서 (0,0)/(2,2) 순위가 하위권으로
  이동하거나, holdout에서 B&H 대비 Sharpe·MDD 동시 열위면 폐기.
- 파라미터(10/5/60/60/3분위)는 잠정 고정값 — 스윕 금지, 재튜닝 시 스터디 재실행.
