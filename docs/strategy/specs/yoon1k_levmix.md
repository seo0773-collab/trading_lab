# 전략 명세: yoon1k_levmix

> `yoon2` 방어형 코어에 레버리지 ETF B&H 슬리브를 상위 계층에서 혼합한 파생 전략.
> 목표는 기존 50/50 패시브 B&H와 유사한 MDD를 허용하는 대신 상승폭을 키우는 것이다.

## 1. 구조

| 항목 | 값 |
| --- | --- |
| strategy_id | yoon1k_levmix |
| 코어 | yoon2 60% |
| 레버리지 슬리브 | QLD(2x Nasdaq100) 40% |
| 리밸런싱 | 월간 |
| 기준 통화 | KRW, USD 슬리브는 USD/KRW 환산 |
| 벤치마크 | yoon1k와 동일한 50/50 SPY원화+KODEX200 |

`UPRO/TQQQ`는 히스토리가 짧아 2008 구간 검증이 약해진다. QLD는 2006년 상장이라
2007년 이후 표본을 보존하면서 나스닥 100의 장기 상승 레버리지 노출을 제공한다.

## 2. 검증 목적

기존 yoon2는 MDD를 크게 낮추지만 강한 상승장에서 B&H보다 상승폭이 작다. 이 변형은
방어형 코어 60%를 남겨 급락 완충을 유지하고, QLD 40%를 월간 리밸런싱으로 붙여
B&H 수준의 낙폭을 감수하는 공격형 변형이다.

## 4. 주의

- QLD 40%는 나스닥 100 레버리지 집중 노출이다. 2000년대 초 닷컴 붕괴 같은 QLD
  상장 전 구간은 실측 검증하지 못한다.
- 일일 리셋 레버리지 ETF의 변동성 손실은 실제 가격에 포함되지만, 세금·환전비용은
  별도 모델링하지 않았다.
- 방어형 yoon1k와 달리 이 변형은 MDD를 B&H 수준까지 의도적으로 키운다.
