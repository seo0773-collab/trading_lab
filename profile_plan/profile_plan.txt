
# Order: 멀티플 × 기울기 2D 상태공간 조건부 백테스트

## 목적
가격 위치(SMA200 멀티플)와 SMA200 기울기 레짐의 결합 상태가 forward return을 유의하게 분리하는지 검증한다.
전략 구현 이전 단계이며, 산출물은 **조건부 기대수익 테이블과 가설 검증 리포트**다.

## 환경
- 위치: `trading_lab` (기존 프로젝트 구조 유지, 모듈식으로 추가)
- Python + JupyterLab, 데이터는 ccxt로 BTC/USDT 일봉 최대 히스토리 수집 (기존 수집 코드 있으면 재사용)
- 사용자가 기존 코드를 첨부할 수 있으므로, 지표 계산부는 독립 함수/모듈로 분리할 것

## 지표 계산 스펙
```
cycle      = SMA(close, 200)
multiple   = close / cycle
slope_pct  = (cycle - cycle.shift(5)) / cycle.shift(5)
slope_z    = slope_pct / rolling_std(slope_pct, 252)
angle_deg  = degrees(arctan(slope_z))          # z=1 → 45°
```
- 파라미터(200, 5, 252)는 상수로 두되 함수 인자로 노출

## 분석 단계
1. **셀 분할**: multiple × angle을 각각 3분위(또는 4분위)로 나눠 3×3 / 4×4 그리드 구성.
   - bin 경계는 **expanding window percentile**로 산출해 look-ahead 금지. 전체 기간 percentile로 경계를 정하는 것은 금지.
2. **forward return**: 5 / 20 / 60일 수익률. 셀별 mean, median, t-stat, 샘플 수, 승률 테이블 산출.
   - overlapping return 문제 → Newey-West 표준오차 또는 block bootstrap으로 t-stat 보정.
3. **정보 추가성 검증**: multiple 단독 조건부 수익 vs 2D 조건부 수익 비교. 기울기 축이 실제로 분리력을 추가하는지 판단.
4. **walk-forward 안정성**: 기간을 3개 사이클로 분할 (~2017 / 2018~2021 / 2022~) 후 셀별 엣지의 부호·크기 일관성 확인.
5. **가설 검증** (우선순위 순):
   - H1: 낮은 멀티플 × 상승 기울기 = 유의한 양(+)의 forward return (눌림목 알파)
   - H2: 낮은 멀티플 × 하락 기울기 = 유의하게 나쁜 forward return (떨어지는 칼 회피 필터)
   - H3: 기울기 극단 bin 도달 후 감속 시 높은 멀티플 구간의 forward return 악화 (익절 타이밍)

## 주의사항
- look-ahead bias 원천 차단: 모든 rolling/expanding 계산은 shift 확인, bin 경계 포함
- 셀당 샘플 최소 기준(예: 50개 미만 셀은 통계 판정 제외) 명시
- 다중비교: 셀 수 × horizon 수만큼 검정이 늘어나므로 Bonferroni 또는 FDR 언급
- 수수료/슬리피지는 이 단계에서 제외 (전략화 단계에서 반영)
- 과최적화 방지: 파라미터 스윕 금지, 위 고정 파라미터로만 1차 실행
