# 전략 명세: yoon2a

> `yoon2` 방어형 코어에 **생존편향을 회피한** 레버리지 슬리브를 상위 계층에서 혼합한
> 공격형 파생 전략. `yoon1k_levmix`(QLD 2x Nasdaq100)·`yoon1a`(USD 2x Semiconductors)가
> 사후적으로 가장 잘 나온 섹터/지수를 손픽한 것과 달리, yoon2a는 광의 시장
> **S&P500 2x(SSO)** 만 쓴다. "어떤 섹터가 이길지"를 모르는 상태에서도 정직하게
> 재현되는 레버리지 노출을 목표로 한다.

## 2. 설계 근거: 왜 SSO인가 (생존편향 제거)

QLD(나스닥100)·USD(반도체)는 **지난 20년 미국 증시에서 가장 강했던 섹터를 사후에
고른 것**이라, 그 초과수익 상당 부분은 전략의 알파가 아니라 hindsight 선택편향이다.
"QLD 같은 레버리지"를 생존편향 없이 쓰려면 특정 섹터가 아닌 **시장 전체**에 레버리지를
걸어야 한다 → S&P500 2x = **SSO**.

- SSO는 **2006-06 상장**이라 2008 금융위기 구간까지 실측된다(UPRO/TQQQ는 2009~2010
  상장이라 2008 스트레스 표본이 없다 — `yoon1k_levmix`가 QLD를 고른 논리와 동일).
- 광의 지수라 단일 섹터 집중·붕괴 리스크가 QLD/USD보다 작다.

## 3. 비중 재최적화 (2007-01-29~2026-06-26, 원화 기준, phase=all)

> **개정 이력**: 초기 채택값은 65/35(Strict 단독: MDD≤B&H에서 CAGR 최대)였으나,
> 점검 결과 65/35의 Sharpe(1.025)가 50/50 B&H(1.089)보다 **낮은** 위험조정 열위가
> 드러났다. 2026-06-29 재최적화에서 **Sharpe≥B&H 제약을 추가**하고 1%p 미세격자로
> 재스윕해 **코어 74% / SSO 26%** 로 변경했다(`reports/profile_sizing/yoon2a_sso_reopt.md`).

yoon2 코어 + SSO 월간 리밸런싱 1%p 격자 주요 지점:

| 코어/SSO | CAGR | MDD | Sharpe | MDD≤B&H | Sharpe≥B&H |
| ---: | ---: | ---: | ---: | :-: | :-: |
| **74/26 (채택)** | **17.20%** | **-26.25%** | **1.097** | ✓ | **✓** |
| 70/30 | 17.63% | -28.10% | 1.065 | ✓ | ✗ |
| 65/35 (구 채택) | 18.16% | -30.38% | 1.025 | ✓ | ✗ |
| 63/37 (Strict 단독 최적) | 18.36% | -31.29% | 1.009 | ✓ | ✗ |
| 60/40 | 18.65% | -32.63% | 0.985 | ✗ | ✗ |
| 50/50 패시브 B&H | 16.78% | -31.35% | 1.089 | — | — |

**채택: 코어 74% / SSO 26%.** 50/50 패시브 B&H를 **MDD(-26.25% vs -31.35%)와
Sharpe(1.097 vs 1.089) 양 축에서 동시에 지배**하면서 CAGR도 +0.42pp 높은,
Sharpe≥B&H 영역의 최대 CAGR 조합이다. train/validation Sharpe가 SSO 비중에 단조
감소해 낮은 비중일수록 OOS가 견고하다는 점도 26%를 뒷받침한다.

- 순수 공격형(MDD를 B&H까지 허용)을 원하면 Strict 단독 최적은 **63/37**(CAGR 18.36%,
  MDD -31.29%)로, 구 65/35의 상위호환이다. 단 Sharpe(1.009)는 B&H 미달이다.

### 손픽 대비 — 제거된 생존편향 프리미엄

| 변형 | 레버리지 | CAGR | MDD |
| --- | --- | ---: | ---: |
| yoon1k_levmix | QLD 2x Nasdaq100 60% | 23.65% | -31.69% |
| yoon1a | USD 2x Semiconductors | 26.93% | -32.38% |
| **yoon2a** | **SSO 2x S&P500 (74/26)** | **17.20%** | **-26.25%** |

QLD/USD 대비 큰 CAGR 차이가 곧 "어느 섹터가 이길지를 사후에 안다"는 가정에서 나온
hindsight 프리미엄이다(단 두 손픽은 비중 기준이 달라 직접 비교는 참고용). yoon2a는
그 가정을 버린 정직한 하한선이며, B&H를 위험조정으로 지배하는 26% 비중을 택했다.

## 4. 구조

```
[상위] yoon2a — 월간 리밸런싱

   └─ SSO 2x S&P500 26%  (USD→KRW 환산, buy & hold)
```

## 5. 주의

- SSO는 일일 리셋 2x ETF라 변동성 손실(decay)이 실제 가격에 포함된다. 세금·환전비용·
  정수주 제약은 별도 운영 레이어에서 확인한다.
- SSO 상장(2006) 이전 구간(예: 2000년대 초 닷컴 붕괴)은 실측 검증하지 못한다.
- 방어형 yoon1k보다는 공격적이나, 26% 비중에서는 MDD(-26.25%)가 B&H(-31.35%)보다
  오히려 얕다. 순수 공격형(63/37, MDD를 B&H까지 허용)을 원하면 §3 각주 참조.
- live_eligible=False (실거래 미승인). OOS(validation/test) 구간 재확인 후 승격 검토.
